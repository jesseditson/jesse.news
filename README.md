# jesse.news

The source of [jesse.news](https://jesse.news), a personal social site built with [Archival](https://archival.dev). Posts are TOML files in `objects/`, templates are Liquid in `pages/` and `layout/`, browser scripts are TypeScript in `src/`, and `carriers/` holds the server code for comments, likes, the newsletter, and replies and likes from the fediverse and Bluesky.

This is a read-only copy, updated from the site's own repository. Secret fields are blanked, so set your own before deploying a copy. Run it locally with `archival run`.
